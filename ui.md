
我们将采用现代、简洁的设计风格，默认以**浅色模式（Light Mode）**为例进行描述。

---

### 核心色彩与风格定义 (Style Guide Idea)

*   **主色调 (Primary Color):** 一种舒适的蓝色 (例如 #007BFF)，用于按钮、链接和强调。
*   **背景色 (Background):** 浅灰白 (#F8F9FA) 或纯白 (#FFFFFF)。
*   **文本色 (Text):** 深灰 (#333333) 用于正文，浅灰 (#666666) 用于辅助信息。
*   **夜间模式 (Dark Mode):** 深色背景 (#121212)，浅色文字 (#E0E0E0)，主色调适当降低亮度。

### 1. 主页 (Homepage) - 设计布局

主页采用经典的电商/内容平台三栏布局或两栏布局，这里推荐 **“顶部通栏 + 左侧导航 + 右侧主内容”** 的结构，信息展示效率更高。

#### 顶部工具栏 (Header Bar) - 固定在顶部，高度约 60px

```text
+-------------------------------------------------------------------------------------------------------+
| [Logo图标] 悦读小说网      |  🔍 [ 输入书名/作者/标签         ] [搜索按钮]  |  [🌞/🌛切换]  [(头像) v] |
+-------------------------------------------------------------------------------------------------------+
```

*   **交互说明:**
    *   **Logo:** 点击返回首页。
    *   **搜索框:** 聚焦时显示热门搜索词下拉。
    *   **日夜切换:** 点击图标，整个网站 CSS Theme 瞬间切换。
    *   **头像:** 鼠标悬停或点击，弹出下拉菜单：
        *   `[个人中心]`
        *   `[我的书架]`
        *   `[账号设置]`
        *   `---分割线---`
        *   `[退出登录]`

#### 内容区域 (Main Content Body)

```text
+---------------------+-----------------------------------------------------------------------+
| **分类导航**        |                                                                       |
| [📚 全部作品]       |  **推荐位 / 轮播图区域 (Banner)** (可选大图推荐)                      |
|                     |                                                                       |
```

    *   **左侧导航:** 选中状态要有背景色高亮。

### 5. 我的书架页 (My Bookshelf) - 用户核心功能

重点在于清晰展示和便捷管理。

```text
(顶部工具栏同主页)

+-----------------------------------------------------------------------------------+
| **我的书架**                                                                      |
+-----------------------------------------------------------------------------------+
| +-------------------------------------------------------------------------------+ |
| | 排序: [🕐 最近阅读 v] (下拉: 最近更新, 书名A-Z)  |  视图: [📜列表] [🔲网格]  | |
| | [✅批量管理]                                                                  | |
| +-------------------------------------------------------------------------------+ |
|                                                                                   |
| **(视图模式 A: 列表视图 - 默认推荐)**                                             |
| +-------------------------------------------------------------------------------+ |
| | [封面] **书名**           | **最新章节**          | **阅读进度** | **操作**   | |
| |---------------------------|-----------------------|--------------|------------| |
| | [图] 斗破苍穹 (天蚕土豆)  | 第1600章 大结局(下)   | [|||||| 98%] | [继续阅读] | |
| |                           | 更新于: 昨天 18:00    | 读至: 第1580章| [移出]     | |
| |---------------------------|-----------------------|--------------|------------| |
| | [图] 诡秘之主 (爱潜水...) | 第五章 序列9占卜家    | [|| 15%     ] | [继续阅读] | |

| +-------------------------------------------------------------------------------+ |
| (分页控件: < 1 2 3 > )                                                            |
|                                                                                   |
| **(视图模式 B: 网格视图 - 切换后显示)**                                           |
| +-----------------------+  +-----------------------+  +-----------------------+   |
| | [    大封面图     ]   |  | [    大封面图     ]   |  | [    大封面图     ]   |   |
| | **斗破苍穹**          |  | **诡秘之主**          |  | **凡人修仙传**        |   |

| +-----------------------+  +-----------------------+  +-----------------------+   |
+-----------------------------------------------------------------------------------+
```

*   **UI细节:**
    *   **阅读进度条:** 可视化展示阅读状态，增加成就感。
    *   **列表视图:** 更强调信息密度和更新状态。
    *   **网格视图:** 更强调封面视觉冲击力，适合书少的时候。
    *   **批量管理:** 点击后，每本书前出现复选框，底部出现“批量删除/移动”操作栏。
